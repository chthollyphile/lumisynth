# 界面多语言（i18n）

界面文字用 [i18next](https://www.i18next.com/) + react-i18next。现在有简体中文（原文）和英文。

## 结构

```
src/i18n/
  index.ts            初始化、语言检测与切换、LANGUAGES（可选语言）、给组件以外用的 t
  catalog.ts          风格包的名字（packLabel / packShortLabel / packDescription）、段落性质
  i18next.d.ts        t() 的键按中文字典做类型检查
  locales/
    zh/<命名空间>.json  原文
    en/<命名空间>.json
    <语言>/index.ts     把这个语言的命名空间汇总起来
electron/
  locales.json        桌面版主进程自己的几句话（macOS 菜单、检查更新的对话框）
  i18n.cjs            主进程读页面 <html lang> 跟着界面语言，读不到时用系统语言
```

命名空间按界面区域分：`common`（共用的词、段落性质）、`commands`（命令、菜单）、`workbench`（外壳、状态栏、面板）、`arrange`（编排、分镜、大纲、时间轴）、`inspector`、`media`（素材、背景、片段）、`look`（画面与编排设置、字体）、`song`（歌曲、歌词、走带、预览）、`script`、`ai`、`theme`（主题编辑器）、`wizard`、`export`、`problems`、`project`（工程动作的消息）、`packs`（风格包名字）。

## 写代码时

- React 组件：`const { t } = useTranslation('inspector')`；要用别的命名空间就 `useTranslation(['inspector', 'common'])`，再写 `t('common:auto')`。
- 组件以外（命令、右键菜单、日志、错误信息）：`import { t } from '@/i18n'`，写全名 `t('media:menu.delete')`。**在用到的时候再取文字**，不要在模块顶层算好存起来，否则切换语言后不会变。命令的 `title` / `category`、菜单的 `label` 因此都是函数。
- 键写错、字典里没有，`tsc` 就报错（类型来自中文字典）。
- 数量：传 `count`。中文只写一个键；英文写 `_one` / `_other` 两个。
- 句子里夹着链接、代码这类元素时用 `<Trans>`，字典里写 `<link>…</link>`、`<code>…</code>`。
- 不要拼接半句话（英文语序不同）；整句放进字典，用 `{{变量}}` 插值。

## 加一种语言

1. 复制 `src/i18n/locales/en/` 为 `locales/<语言代码>/`，翻译里面的 JSON，改 `index.ts` 的注释。
2. 在 `src/i18n/index.ts` 的 `resources` 与 `LANGUAGES` 里各加一行（`label` 用这种语言自己的写法，`htmlLang` 是 `<html lang>` 的值）。
3. 在 `electron/locales.json` 里加同一种语言。
4. `npm test`：`test/unit/i18n/locales.test.ts` 检查每种语言的键、插值变量与中文一一对应（复数形式算同一个键）。

`locales/<语言>/index.ts` 是手写的，一个命名空间一行（加命名空间时各语言都要加）。

## 语言怎么选

界面语言存在 `localStorage` 的 `lumisynth:language`，不进工程文件。没选过就按浏览器的语言偏好挑第一个支持的，都不支持用英文。切换入口：「视图 › 界面语言…」（命令面板里也有）、「设置」编辑器顶部的下拉框、手机布局右上角的「更多」。

测试里固定用中文：单测在 `test/setup.ts` 里切到中文；Playwright 的两套配置都设了 `locale: 'zh-CN'`。英文界面有一条专门的测试（`workbench.spec` 的 `English interface`）。

## 还没翻译的部分

第一步只做了界面本身。下面这些暂时还是中文，按需要再做：

- 风格包目录：族、风格、转场、组件槽与选项的名字和说明（`src/packs/*`），以及各包自己的设置面板（`src/packs/*/settings.tsx`）。风格包的名字与简介已经在 `packs` 命名空间里。
- LumiScript：剧本里生成的注释、诊断信息（`src/script/*`），编辑器的补全与悬停说明（`src/app/script/lumiscript.ts`）。
- agent 工具的返回信息与工具标题（`src/agent/*`）、写剧本的 skill 文档。
- AI 提示词与 AI 生成内容的语言（主题名字、编排说明仍按中文要求模型输出）。
